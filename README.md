# Akshara Academy — demo coaching center website

A portfolio demo by Hrushikesh C. Built with React and Vite.

## Run it on your laptop

```bash
npm install
npm run dev
```

Open the link it prints (usually http://localhost:5173).

## Reuse it for a real client

Almost all the text lives in `src/data.js`: business name, phone, WhatsApp
number, address, hours, courses, results, faculty, testimonials and batches.
Change those values and the whole site updates. Colors are at the top of
`src/index.css`.

## Deploy on Vercel

1. Push this folder to a new GitHub repository.
2. On vercel.com, click **Add New → Project** and import the repository.
3. Vercel detects Vite automatically (build command `npm run build`, output
   folder `dist`). Click **Deploy**.
